# From Numerical Methods to SHYFEM

This Slidev project is both:

- a progressive learning path toward the SHYFEM hydrodynamic model;
- reusable teaching material for a Numerical Modeling course.

## Working principle

New material is added only after the underlying concept has been studied and checked.
Each topic follows the same structure:

1. Definition
2. Physical meaning
3. Mathematical formulation
4. Numerical discretization
5. Minimal example
6. Connection to SHYFEM

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Export to PDF

```bash
npm run export
```

## Content status

- `PLANNED`: structure defined, content still to be studied.
- `DRAFT`: initial content added, scientific review pending.
- `VERIFIED`: equations, assumptions, and examples checked.
- `TEACHING-READY`: reviewed for clarity, timing, and classroom use.
